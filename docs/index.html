操作说明

  • W/↑ 加速
  • S/↓ 刹车（减速滑行）
  • A/D 左右变道抓鱼
  • 空格 跳跃
  • T 轮滑特技
  • B 打铃
  • H 指锅加油
  • C 切换镜头
  • Q/E 切换滑行节奏
  • N 时间快进 3 小时
  • M 音乐开关
  • K 截图 · F 全屏
  • U 隐藏界面
  • P 暂停

拖拽旋转视角、滚轮缩放。点击指锅为她加油，点击远处海面会有鱼跃出。几秒不操作会自动滑行去追鱼；金色的鱼值 5 分。背景音乐是实时合成的，节奏跟随步频。
